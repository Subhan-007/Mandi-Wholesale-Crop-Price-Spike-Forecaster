# Mandi-Wholesale-Crop-Price-Spike-Forecaster
This is a web-based early-warning tool. It tracks five staple crops(Onion, Tomato, Potato, Garlic, Green Chilli) across five major Punjab markets. Users enter a crop, city, current wholesale price, last week's price, and recent rainfall into a browser form to receive a 7-day price estimate and a spike risk alert(Normal, Moderate Rise, Sharp Spike).
